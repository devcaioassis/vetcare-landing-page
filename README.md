# VetCare Landing Page

Bem-vindo ao repositório da **VetCare**! Este projeto é uma Landing Page responsiva e interativa desenvolvida para uma clínica veterinária fictícia. O objetivo é demonstrar na prática o que eu aprendi nas aulas de HTML, CSS e Javascript do programa Dev Full Stack da +praTi 2026.


**[Acesse o projeto online clicando aqui](https://devcaioassis.github.io/vetcare-landing-page/)**

---

## Funcionalidades

* **Design Responsivo:** A página se adapta perfeitamente a telas de celulares, tablets e computadores de mesa, garantindo uma ótima experiência de leitura.
* **Integração com API Externa (ViaCEP):** O formulário de contato possui inteligência para preencher automaticamente o endereço completo (rua, bairro, cidade e estado) assim que o usuário digita um CEP válido.
* **Validação e Feedback:** Mensagem de sucesso estilizada que aparece após o envio do formulário, melhorando a experiência do usuário e oferecendo a opção de fazer um novo agendamento.
* **Ícones Otimizados:** Utilização de ícones no formato SVG para garantir leveza e alta resolução no rodapé.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes bases da web:

* **HTML5:** Semântica e estruturação do conteúdo.
* **CSS3:** Estilização geral, variáveis de cores, Flexbox e Media Queries para organizar o layout da página e deixar ela responsiva.
* **JavaScript (Vanilla):** Manipulação do Documento (DOM), consumo de API (Fetch API) e interatividade.
* **Git & GitHub:** Versionamento de código e hospedagem via GitHub Pages.

## 💻 Como rodar o projeto localmente

Caso queira fazer o download e testar este projeto na sua própria máquina, siga os passos abaixo:

1. Clone este repositório no seu terminal:

2. Abra a pasta do projeto no seu editor de código favorito (ex: VS Code).
